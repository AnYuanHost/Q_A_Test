针对你目前的情况——已有产品或初步成果、参加企业主办的创新创业比赛、目标是争取投资或资金支持——建议将项目计划书定位为一份兼具产品验证、商业可行性和投资价值的融资型商业计划书。

这类计划书不能只介绍产品有多创新，更需要让企业评委或投资决策者相信：产品值得做、市场确实需要、团队有能力执行、投入资金后能够形成可衡量的成果。

由于你还没有确定项目名称和行业，下面先提供一套可直接填写、适合多数行业的定制方案。等你补充项目资料后，再进一步调整为具体赛道版本。

# 一、先明确这份计划书要说服评委什么

1. 产品已经具备什么基础？

用产品原型、实测数据、试点应用、用户反馈等证明项目不是停留在概念阶段。

2. 谁会购买，为什么购买？

说明目标客户、真实需求、支付意愿、市场规模和现有解决方案的不足。

3. 投资之后能产生什么成果？

把资金需求与产品升级、客户拓展、收入增长、规模化交付等具体里程碑关联起来。

4. 为什么值得这个企业支持？

说明项目与主办企业的技术、客户、渠道、供应链或产业布局有什么协同机会。

## 二、建议采用的计划书目录

建议正文控制在约 12—18 页，另附证明材料。若赛事有指定页数或格式，以官方要求为准。

| 页码建议 | 章节 | 评委重点关注 |
| --- | --- | --- |
| 1 | 封面 | 项目定位是否清晰 |
| 2 | 项目摘要 | 为什么值得投资或支持 |
| 3—4 | 市场痛点与商业机会 | 需求是否真实、市场是否足够 |
| 5—7 | 产品介绍与核心创新 | 产品是否有竞争力、是否可行 |
| 8—9 | 商业模式与竞争分析 | 如何获客、如何盈利 |
| 10—11 | 产品验证与市场进展 | 是否有真实成果和客户证据 |
| 12 | 市场拓展与企业合作 | 能否利用主办企业资源落地 |
| 13—14 | 财务预测与资金使用计划 | 需要多少钱、用在哪里、产生什么结果 |
| 15 | 团队与实施计划 | 是否具备执行能力 |
| 16 | 风险分析与退出或回报路径 | 风险能否控制、投资逻辑是否合理 |
| 附件 | 证明材料 | 核心论点是否有证据支持 |

这里的“退出或回报路径”要结合实际融资方式来写。如果比赛只提供奖金、项目补助或资源支持，而不涉及股权投资，就应重点说明资金使用和项目成果，不必硬写股权退出方案。

# 五、财务与投资部分，建议重点打磨

既然你的目标是争取投资或资金支持，财务部分不宜只放一张三年收入预测表。建议准备三个相互关联的表格。

## 1. 单位经济模型

以一个典型产品、订单或客户为计算单位。

| 指标 | 填写内容 |
| --- | --- |
| 平均售价 | 【每件/每单/每客户的收入】 |
| 单位直接成本 | 【生产、交付、服务等成本】 |
| 单位毛利 | 售价－单位直接成本 |
| 获客成本 | 【获得一个付费客户的平均成本】 |
| 回款周期 | 【从交付到收款的时间】 |
| 客户复购或续约 | 【实际数据或合理假设】 |

这张表可以帮助评委判断，项目能否随着销售增加而持续创造价值。

## 2. 资金使用与里程碑对应表

资金申请最好采用“资金用途—实施时间—验收成果”的逻辑，而不是只列工资、设备和推广等支出。

例如：

- 研发投入 → 完成指定功能、性能测试或产品版本。
- 试点投入 → 完成指定数量的试点并形成验证报告。
- 市场投入 → 获得明确数量的有效客户或付费订单。
- 交付投入 → 达到特定产能、交付周期或服务能力。

具体指标应根据你的行业和现有基础设定，不能为了显得有竞争力而随意承诺。

## 3. 三种经营情景

- 平均售价与毛利率
- 产品开发和交付成本
- 客户回款周期
- 资金到位时间
