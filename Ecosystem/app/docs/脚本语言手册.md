# 解决方案脚本语言手册

***

面向写 `.lan` / `.pi` 的人（与 AI）。规则来自 `solution-script-writing` skill 与 `Doc/MD` 语法文档；本手册是可检索的合并版。

***

## 1. 文件结构

一个解决方案 = 主文件 `.lan` + 参数表 `.pi`。

```text
{
    // 前图（替换前）
}
{
    // 后图（替换后）
}
```

- 前图为空 `{ }` 表示从零构造整张图（bootstrap）。
- 顶层必须是**成对**的前图 / 后图。

## 2. 节点（四段）

```text
映射名
( 定义域参数 )
值域参数
节点状态
```

- 每段独占一行，顺序固定；定义域多参数用 `( A B )`。
- 映射名必须能在文档/静态库中唯一确定。

## 3. 节点状态

| 状态 | 含义 | 用法 |
|---|---|---|
| `Tractable` | 可执行 | 入口节点（无前置） |
| `TraUntractable` | 前置完成后**直接**可执行 | 无外部等待的链式节点（最常用） |
| `Pending` | 前置完成后仍需等待 | 受外部条件调控 |
| `Untractable` | 前置完成后只进 Pending | 需要知识库决策的节点 |

## 4. 并行块

```text
[
    WorkA
    EmptyElement
    ResultA
    TraUntractable
][
    WorkB
    EmptyElement
    ResultB
    TraUntractable
]
```

硬性规则：

1. `[]` 首尾必须是**节点**；
2. **禁止嵌套** `[]`；
3. 块内节点与前后节点全连接。

## 5. 参数表（`.pi`）

每行五字段，空白分隔：

```text
参数名  类型  基础信息  语境  参数状态
```

| 字段 | 取值 | 说明 |
|---|---|---|
| 参数名 | 与脚本逐字一致 | 主键 |
| 类型 | `String` / `UInt` / `SuperIndex` / `Bool` | 仅用于信息生成，不等于运行时类型 |
| 基础信息 | 由类型决定 | 如 `UInt` 的初值 |
| 语境 | `Unlimited` 或已登记语境 | 优先 `Unlimited` |
| 参数状态 | `Login` / `Logout` / `Common` / `LoginOut` | 计算用参数用 `Login`；占位用 `Common` |

`EmptyElement` 固定行：

```text
EmptyElement  EmptyElement  EmptyElement  Unlimited  Common
```

## 6. 常数（生态层扩展）

```text
const UIntTen = 10;
```

展开为：1 个 `NewUIntElement` + 10 个 `UIntSuccessor`，并自动补

```text
UIntTen UInt 10 Unlimited Login
```

> 内核原生支持前，用「脚本工作台 / 常数管理插件 / `qaconst.hpp`」展开。

## 7. 完整示例

```text
{
}
{
    [
        NewUIntElement
        EmptyElement
        UIntA
        Tractable

        UIntSuccessor
        UIntA
        UIntA
        TraUntractable
    ][
        NewUIntElement
        EmptyElement
        UIntB
        Tractable
    ]

    UIntAdd
    ( UIntA UIntB )
    UIntC
    TraUntractable

    [
        ReleaseElement
        EmptyElement
        UIntA
        TraUntractable
    ][
        ReleaseElement
        EmptyElement
        UIntB
        TraUntractable
    ][
        ReleaseElement
        EmptyElement
        UIntC
        TraUntractable
    ]
}
```

参数表：

```text
EmptyElement  EmptyElement  EmptyElement  Unlimited  Common
UIntA String UIntA Unlimited Login
UIntB String UIntB Unlimited Login
UIntC String UIntC Unlimited Login
```

## 9. 常见错误

| 错误 | 后果 | 修正 |
|---|---|---|
| 节点只有三段 | 无法确定原子映射 | 补状态段 |
| `[]` 内嵌套 `[]` | 图结构非法 | 拆成同级多组 |
| 参数未在 `.pi` 登记 | 运行期找不到参数 | 补行（`pi-helper` 可一键补齐） |
| 定义域参数个数不符 | 映射无法匹配 | 查映射文档的集合元数 |
| `Untractable` 用在无外部条件的链上 | 流程停住 | 改用 `TraUntractable` |
| 释放映射用了 `ReleaseElement` 释放复杂结构 | 子内存泄漏 | 用专用释放映射 |
