# 术语表

***

本表统一"内核文档 / 代码 / 工作区"三处的叫法。查不到的词先查 `文档索引.md` 与 `Q_A_Test-master/Doc/MD`，不要凭猜测。

***

## 1. 基础框架

| 术语 | 英文 / 代码 | 含义 |
|---|---|---|
| 元素 | Element (`E_S_M`) | 一段可知大小的内存（`Size` + `KeySpace`），所有操作的实体 |
| 集合 | Set | 用判定函数描述的元素集合；决定元素"能用哪些映射" |
| 映射 | Map | 定义域集合 + 值域集合 + 执行函数；脚本节点的原子动作 |
| ESM | Element-Set-Map | 元素-集合-映射框架，整个工程的地基 |
| 转交 / 引用 | `&=` / `\|=` | 元素传递方式；引用需 `ZeroElement` 解除 |
| 空元素 | `EmptyElement` | 占位元素，映射不需要真实输入时使用 |

## 2. 智能体与运行

| 术语 | 英文 / 代码 | 含义 |
|---|---|---|
| 总元素环境检索器 | EES / `ESM_Manage` | 符号表 + 语境管理，管理子检索器、超索引检索器、元素环境 |
| 子元素环境检索器 | SubEES | 某个语境下的信息检索器（字典序 / 8 比特 / 超索引） |
| 语境 | Context | 问题发生的共同场景；一个语境对应一个子检索器 |
| 超索引 | SuperIndex | 系统统一的元素编号；`KRS\<编号>.txt` 即其落盘 |
| 超索引检索器 | SIS | 超索引 → 元素环境地址 的中间层 |
| 元素环境 | ElementEnvironment | 真正存放元素的容器 |
| 零轮询机 | ZPD / `KRSPollingDrivenZero` | 管理智能体运行逻辑的虚拟机 |
| 轮询机 | PollingDriven | 领取一个可执行节点并执行的线程单元 |
| 问答流图 | QuestionFlowMap | 以问题为节点、依赖为边的有向图 |
| 节点状态 | `Tractable` / `Pending` / `Untractable` / `TraUntractable` | 可执行 / 等待 / 不可执行 / 前置完成后直接可执行 |
| 图后推 | BackPush | 节点完成后推动其后置节点状态转移 |
| 解决方案 | Solution | 描述"如何把父问题拆成子问题"的子图替换信息 |
| 子图替换 | Subgraph Replacement | 移除节点、添加节点、重连前后置关系 |
| 理想问题 / 实际问题 | Ideal / Reality Question | 希望解决的问题 / 当前可执行解决的问题 |
| 诉求 | — | 用户侧的问题描述，进入系统后成为问答节点 |

## 3. 知识表示

| 术语 | 英文 / 代码 | 含义 |
|---|---|---|
| KRS | Knowledge Representation System | 知识表示系统；`KRS\` 为数据目录 |
| 意向性对象 | Intentionality Object | 序偶⟨质性, 质料⟩ |
| 质性 | Qingzhi | 对象 + 意向特征（可检索的知识节点） |
| 质料 | Zhiliao | 非对象内容（内容本身，不直接检索） |
| 意向性网络 | Intentionality Network | 意向性对象 + 指向关系（双链） |
| 知识图谱 | Knowledge Graph | 意向性对象的组织形态 |
| 溯源器 | Ascender | 按顺序访问知识节点、获取质料的管理器 |
| 临时知识 | Temporary Knowledge | 运行期构建、由临时超索引管理器分配的过渡知识 |
| 描述逻辑 | ALC | 可判定、可完备推理的逻辑体系（后续目标） |
| 非公理 | Non-Axiomatic | 不依赖公理、允许矛盾与修正的推理路线 |
| 双链 | `[[目标]]` | Obsidian 风格的知识引用，用于构建知识网络 |

## 4. 脚本与生态

| 术语 | 英文 / 代码 | 含义 |
|---|---|---|
| 解决方案脚本 | `.lan` | 前图/后图的替换规则文件 |
| 参数表 | `.pi` | 脚本参数的五行登记表 |
| 节点四段 | mapping / domain / range / state | 每段独占一行，四段构成一个节点 |
| 并行块 | `[ ]` | 块内节点无数据依赖、可并行；**禁止嵌套**，首尾必须是节点 |
| 常数声明 | `const X = N;` | 生态层扩展语法，展开为 `NewUIntElement + N×UIntSuccessor` |
| 映射文档 | `*.md`（`Doc/MD`） | 每个映射一篇，含定义域/值域/案例 |
| 案例文档 | `*_Case.md` | 跨实体的综合演示 |
| 能力目录 | `能力目录.md` | 插件/技能/文档/映射的统一清单 |
| 工作区 | Workbench | 控制台的 IDE 外壳（活动栏/侧边栏/标签页/面板） |
| 插件 | Plugin | `app/plugins/<id>/`（`plugin.json` + `main.js` + `ui.js`） |
| 插件宿主 | `plugin-host.js` | 后端：扫描/激活/执行命令/SSE 事件 |
| 前端插件库 | `plugin-host.js`（web） | 前端：加载插件 UI、调用命令、订阅事件、编辑器桥 |
| 契约 | `/api/v1/*` | 前端与后端/内核插件之间的 REST 接口约定 |
| SSE | Server-Sent Events | 插件向前端推送事件的单向流 |
