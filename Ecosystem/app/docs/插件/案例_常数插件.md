# 案例：常数插件（const-manager）

***

本案例演示一个**实用插件**的端到端流程：把"用常量需要多个小知识库协作"收敛为一次调用。插件同时提供 Node 逻辑与前端面板。

***

## 1. 问题

内核脚本语言没有数值字面量，表达 `10` 需要 1 个 `NewUIntElement` + 10 个 `UIntSuccessor` 节点，且要在 `.pi` 中登记参数。跨多个知识库协作时，这一串约定对人类与 AI 都是负担。

## 2. 插件清单（`app/plugins/const-manager/plugin.json`）

```json
{
  "id": "const-manager",
  "name": "常数管理",
  "version": "0.1.0",
  "main": "main.js",
  "ui": "ui.js",
  "contributes": {
    "commands": [
      { "id": "list", "title": "列出常数" },
      { "id": "define", "title": "定义 / 更新常数" },
      { "id": "remove", "title": "删除常数" },
      { "id": "serialize", "title": "生成常数节点序列" },
      { "id": "expand", "title": "展开脚本中的常数" }
    ],
    "panels": [ { "id": "const-manager.table", "title": "常数表", "location": "sidebar" } ]
  }
}
```

## 3. Node 逻辑（节选）

```js
const engine = require('../../web/js/lan-toolkit.js');   // 复用官方脚本引擎（UMD）

module.exports = {
  activate(ctx) {
    const getList = () => (ctx.state.constants || []);
    const setList = (l) => { ctx.state = { ...ctx.state, constants: l }; ctx.emit('changed', l); };
    return {
      commands: {
        async define({ name, value }) { /* 校验 → 入库 → ctx.emit('changed') */ },
        async serialize() {
          const blocks = getList().map((c) => {
            const nodes = ['NewUIntElement', 'EmptyElement', c.name, 'TraUntractable'];
            for (let k = 0; k < c.value; k++) nodes.push('UIntSuccessor', c.name, c.name, 'TraUntractable');
            return nodes.map((t) => '    ' + t).join('\n');
          });
          return { nodes: blocks.join('\n\n'), pi: getList().map((c) => `${c.name} UInt ${c.value} Unlimited Login`) };
        },
        async expand({ lan }) { return engine.expandConstants(lan); },
      },
    };
  },
};
```

要点：**不重新造轮子**——展开逻辑直接复用 `web/js/lan-toolkit.js`（与前端、插件副本同源）。

## 4. 调用（HTTP）

```text
POST /api/v1/plugins/const-manager/command
{ "command": "define", "args": { "name": "UIntTen", "value": 10 } }

POST /api/v1/plugins/const-manager/command
{ "command": "expand", "args": { "lan": "const Seven = 7;\n{\n}\n{\n}", "withLibrary": true } }
```

`expand` 返回：

```json
{
  "expanded": [
    { "name": "UIntFive", "value": 5, "nodes": 6 },
    { "name": "UIntTen", "value": 10, "nodes": 11 },
    { "name": "Seven", "value": 7, "nodes": 8 }
  ],
  "piExtra": ["UIntFive UInt 5 Unlimited Login", "UIntTen UInt 10 Unlimited Login", "Seven UInt 7 Unlimited Login"],
  "warnings": []
}
```

## 5. 前端面板（`ui.js`）

面板提供：定义常数、插入 `const` 声明、插入节点序列、展开编辑器脚本。例如"展开编辑器脚本"：

```js
const r = await host.call('const-manager', 'expand', { lan: host.editor.getText(), withLibrary: true });
host.editor.setText(r.lan);              // 写回编辑器
host.status('已展开并写回编辑器');        // 弹出 toast
```

## 6. 与内核侧的关系

- 本插件工作在**生态层**（`.lan` 生成与展开），不改内核；
- 内核若采纳常数方案（提案路线 A/B，见 `app/docs/常数扩展提案.md`），插件可随之切换为"直接输出字面量节点"。
