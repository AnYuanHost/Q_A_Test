# 插件通信协议

***

"插件 ↔ 前端"的通信库由两侧组成：后端宿主 `server/plugin-host.js` 与前端库 `web/js/plugin-host.js`。二者以 HTTP（命令）与 SSE（事件）通信。

***

## 1. HTTP 端点

统一响应包：`{ "ok": true, "data": ... }` / `{ "ok": false, "error": "..." }`。

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/v1/plugins` | 插件清单（含贡献点、激活状态、已有命令） |
| POST | `/api/v1/plugins/:id/activate` | 激活插件（首次调用命令时也会自动激活） |
| POST | `/api/v1/plugins/:id/command` | 执行命令，体：`{ "command": "...", "args": {...} }` |
| GET | `/api/v1/plugins/events` | 事件流（SSE，`text/event-stream`） |
| GET | `/api/v1/plugins/assets/:id/:file` | 读取插件目录内的静态文件（`ui.js` 等，含路径穿越防护） |

事件流每帧为 `data: {"plugin":"<id>","topic":"<topic>","payload":...}`；每 20 秒发送一次 `: ping` 保活。

***

## 2. Node 侧 API（`ctx`）

`main.js` 导出 `activate(ctx)`，返回 `{ commands }`。

```js
module.exports = {
  activate(ctx) {
    return {
      commands: {
        async hello({ who }) { return { msg: 'hi ' + who }; },
      },
    };
  },
};
```

| 成员 | 说明 |
|---|---|
| `ctx.id` | 插件 id |
| `ctx.manifest` | 清单对象 |
| `ctx.log(...)` | 带插件前缀的日志 |
| `ctx.state` | 持久化状态（读/写都会落盘至 `app/data/plugin-state/<id>.json`） |
| `ctx.setState(obj)` | 等同 `ctx.state = obj` |
| `ctx.emit(topic, payload)` | 向前端推送事件（SSE） |
| `ctx.call(otherId, command, args)` | 调用其它插件的命令 |
| `ctx.appDir` | `app/` 绝对路径（便于定位资源） |

命令返回值会原样作为 HTTP 的 `data` 返回前端。

***

## 3. 前端侧 API（`host`）

`ui.js` 通过 `window.QAPluginHost.registerUI(id, factory)` 注册；`factory(host)` 返回 `{ title, element }`，`element` 会被挂载到「09 插件中心」的面板区。

| 成员 | 说明 |
|---|---|
| `host.id` / `host.manifest` | 插件 id / 清单 |
| `host.call(pluginId, command, args)` | 调用插件命令（含自身），返回 Promise |
| `host.status(msg)` | 触发全局 toast（`qa-status` 事件） |
| `host.editor.getText()` | 读脚本工作台主编辑器（`.lan`）内容 |
| `host.editor.setText(text)` | 写回主编辑器 |
| `host.editor.insert(text)` | 在光标处插入（用于"选映射生成节点"等） |
| `host.bus.on(topic, fn)` | 订阅本插件事件（`topic` 省略则全部） |

> `host.editor` 依赖「06 脚本工作台」已渲染；插件中心在加载插件前会自动确保其已渲染。

***

## 4. 生命周期

1. 前端进入「09 插件中心」→ `QAPluginHost.load()` 拉取清单；
2. 对每个含 `ui` 的插件，动态 `<script>` 加载 `ui.js` 并调用其 `registerUI` 注册的工厂；
3. 前端 `host.call` → 后端 `host.invoke` → 首次自动 `activate`（`require main.js`）；
4. 插件 `ctx.emit` → SSE → 前端 `host.bus` 分发；
5. 进程重启后，`ctx.state` 从状态文件恢复。
