# I_O项目

***

I_O项目被希望用于提供系统和外界环境交互的全部方法，但在实际设计中其定位受到拆分。比如装载动态库等功能已经封装到知识库相关的库中。而在当前的内核中，并不需要提供命令行交互的需求，所以这里仅提供文件交互的基本操作。

基于 E_S_M 框架的文件与命令行 IO 库，提供文件流（Fstream）的字符/文本流读写、Windows 文件地址结构与命令行行级接口。
