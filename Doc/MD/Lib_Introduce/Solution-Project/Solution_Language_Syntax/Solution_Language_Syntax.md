# 解决方案脚本语言语法

***

在本项目中，脚本语言需要维护多个文件，以保证单个脚本语言可以获得足够有用的信息。这些文件分别是脚本语言主文件、参数表文件两个文件。但是在复杂的情况下，仅靠单个解决方案的文件并不足以提供解决方案所有的全部信息，这些信息需要在解释时根据智能体环境进行补充，而这些补充往往涉及多个解决方案的协同。

***

## 解决方案脚本语言语法

| 指令 | 说明 |
| --- | --- |
| [解决方案脚本语言语法](Language_Syntax.md) | 每一个解决方案都需要描述问答流图替换过程中，替换前的图结构以及替换后的图结构，这些信息都有解决方案主语言文件完成提供。在该文件中，需要提供基本的映射信息，定义域与值域参数信息，以及节点的状态信息。 |

***

## 脚本语言参数表语法：

| 指令 | 说明 |
| --- | --- |
| [解决方案参数表语法](Parameter_Syntax.md) | 参数表需要指明参数的所有信息，以方便解决方案工厂等模块使用。脚本语言中只记录参数名，其余的参数信息都需要通过参数表来查询。 |
