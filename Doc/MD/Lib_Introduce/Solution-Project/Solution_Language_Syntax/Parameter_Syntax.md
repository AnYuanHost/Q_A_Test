# 脚本语言参数表语法

***

参数表需要指明参数的所有信息，以方便解决方案工厂等模块使用。脚本语言中只记录参数名，其余的参数信息都需要通过参数表来查询。

***

## 脚本语言参数表格式

脚本语言参数按照一定的格式一条条的记录信息。每一条存储以下信息：

参数名称：用于检索确定（数据库主键）

类型名称：用于确定基本的参数类型

基础信息：用于存储基础信息，基础信息将用于信息生成

语境名称：用于确定语境归属

参数状态：用于记录参数是否需要注册和注销

***

### 参数名称

因为参数名称读取时使用文件读取以获得，所以需要按照标准的字符串读取的格式，比如中间不能夹杂空格或者制表符等等。同时，名称需要保证主文件中所有同一个参数与该名称一致。

***

### （基础信息的）类型名称

当前系统能够接受的基础类型，只有四种系统会使用的基本类型，所以只指明四个关键字：

String 字符串类型：用于记录字符串类型

UInt 无符号整型：用于记录无符号整型数字

SuperIndex 超索引类型：输入无符号整型，但转化为无符号整型

Bool 布尔类型：输入 0 或者 1，转化为 false 和 true

但是需要注意，这些数据类型仅仅是用于参数信息生成，而并不是指实际的映射使用时的数据类型。

***

### 基础信息

基础信息的格式由类型名称指明的类型决定，这些基本格式将会作为基础用于信息生成。

***

### 语境名称

语境名称指明参数属于哪个语境，每一个语境名称都应该在语境表中可以被检索到。而同样的，语境名称也需要以字符串读入的方式完成加载，所以仍需要遵守字符串标准。

语境名称中有一个特定语境名称："Unlimited"，该语境名称指出不需要任何语境信息，由语境字典最后统一分配语境。使用该名称指定的语境，即可以是同一个语境，也可以是不同语境，以方便更自由的确定语境信息。

***

### 参数状态

参数状态通过四个特定的关键字来确定：

Login 注册：被指明该状态的节点会优先进行参数的注册操作

Logout 注销：被指明该状态的节点会优先进行参数的注销操作

Common 普通：被指明该状态的节点不会进行任何注册注销操作

LoginOut 注册销：被指明该状态的节点需要进行注册和注销

***

## 使用案例

```C++
ParameterName UInt 100 ContextName 
```
