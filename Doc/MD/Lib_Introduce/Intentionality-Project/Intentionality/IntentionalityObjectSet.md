# IntentionalityObjectSet

***

集合IntentionalityObjectSet为所有意向性对象的集合，定义为：

```C++
Set IntentionalityObjectSet(EmptyElement, IntentionalityObjectSetTest);
```

意向性对象集合（IntentionalityObjectSet）由所有意向性对象元素组成，用于意向性对象相关操作。

意向性对象是意向性网络中的节点，其内部以超索引组织自身的质性（指向信息）与质料（附属内容），质性锚定另一个固定的意向性对象，可通过意向性索引完成定位。
