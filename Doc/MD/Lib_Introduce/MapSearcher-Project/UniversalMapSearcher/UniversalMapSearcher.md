# UniversalMapSearcher

***

该源文件提供通用的映射检索工具。通用的意思并不是支持任何一种可能的检索方式，而是指任何一个零号轮询机都可以使用该模块来获取同一套检索服务，该检索工具是公开给每一个零号轮询机的。
